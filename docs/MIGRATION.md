# Migration from the four-week workshop

The current course has five competency milestones. The old 25-points-per-week totals, 70-point completion threshold, discretionary bonuses/deductions and cell-order proof of freezing are retired. The supplied v2.0 rubric defines 24 required Met / Not Yet criteria. Module 4 is assessed before integration; Module 5 carries D4.5–D4.7 and final delivery. D identifiers remain stable.

The teaching repository has one canonical lab, a CPU practice workbook and worked CPU solutions per module. Legacy week paths are navigation notebooks, so saved bookmarks still lead to current content without maintaining duplicate executable implementations. Previous versions remain in Git history. The existing week3 slide deck is legacy background, not the current assessment policy.

Existing learner work remains valid evidence if it satisfies the current criteria. Preserve original outputs and explain missing evidence; do not relabel old metrics or fabricate a new experiment. Template data is practice, phrase matching is only a refusal diagnostic, and cosine is only a similarity proxy. Human reviewers judge actual evidence.
