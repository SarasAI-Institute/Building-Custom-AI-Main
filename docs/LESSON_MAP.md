## Differences handled in this pack

- Module 1 has 15 board videos rather than the curriculum base sequence of 11. Tokens/text embeddings occupy Videos 2-4. Positional encoding, feed-forward layers, softmax and Transformer blueprint precede attention in Videos 5-9. Later lessons move to Videos 10-15.
- Module 2 has 12 board videos rather than 9. Keyword and semantic search precede the two RAG introduction lessons, followed by chunking. Retrieval metrics and RAG evaluation are separate theory videos. Notes explain the general metrics while preserving the special RiskLens all-required-sources recall definition.
- Module 3 retains eight board videos but uses revised/reused introductory titles. The board places the data tutorial in Section 2 without a separate loss video. Notes still cover loss, masking, learning rate, epochs and generalization from the supplied curriculum.
- Modules 4 and 5 retain the observed eight- and four-video sequences. The notebook's D4 labels span both modules.
- The board therefore currently lists 47 main-module videos, plus the Module 0 grading orientation. Counts are a production snapshot, not a learner promise. The supplied guide/curriculum still contains an older statement of 40 in-house videos; keep original references unchanged and update that sentence in any future source revision.
